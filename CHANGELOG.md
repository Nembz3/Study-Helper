# Changelog

## 3.4.0 — Activity-Type Detection
- Added dedicated detection for drag-and-drop questions
- Added ordering and sequencing activity detection
- Detects drag instructions even when they appear below a title
- Detects draggable and sortable elements
- Recognises numbered ordering slots
- Uses Submit/Check controls as supporting evidence for interactive activities
- Expanded candidate search so non-standard Seneca question types are not missed
- Preserved V3.3 false-positive protections

## 3.3.0 — High-Confidence Rapid Mode
- Fixed Rapid Mode false positives on course, progress and completion screens
- Added interactive-answer detection and confidence scoring
- Added stronger duplicate protection

## 3.2.0 — Rapid Assist
- Added automatic one-time analysis for each newly detected question
- Added caching and shorter prompts
